# fherma-polymul

A CUDA answer to the FHERMA challenge *Polynomial Multiplication (GPU-Accelerated)*,
specification `polynomial-multiplication/negacyclic@1.0.0`: the exact product
c = a·b mod (X^N + 1, q), coefficients of up to 2048 bits as little-endian u32 limbs.

## Method

Residue number system plus negacyclic NTT plus CRT:

1. **Decompose** each coefficient into residues modulo K primes p_j < 2^31, p_j ≡ 1 (mod 2N),
   enough that their product exceeds 2^20 · 2N · q² (K = 58 at N = 32768, W = 868; 115 at
   N = 65536, W = 1747).
2. **NTT** per prime (four-step split into column and row passes in shared memory), pointwise
   product, inverse NTT.
3. **CRT** back to limbs modulo q, with an exact double-precision rounding.

Inputs are read and the output written directly in the caller's memory through HMM where the
device supports it (staged copies through pinned memory otherwise); the copy mode is chosen by
timing at setup.

## Files

| File | Role |
|---|---|
| `solve.cu` | the answer: kernels and host pipeline (`fherma_init`, `fherma_run`, `fherma_free`) |
| `rns.cuh`, `rns_kernels.cuh`, `rns_plan.h` | arithmetic, the GPU schedule (shared with the CPU check), setup tables |
| `main.cpp`, `fherma.h`, `fherma.toml` | generated by the platform; not edited |
| `CMakeLists.txt` | build (CUDA, `-arch=native`, links cuPQC if present, though it is not used) |
| `solve_cpu.cpp` | the same schedule on the CPU, for testing without a GPU |
| `oracle.py`, `make_big.py`, `run_tests.sh`, `fuzz.py` | test points, references, test matrix (21 points), fuzzing |
| `rns_ref.py` | NumPy model of the algorithm |
| `build.sh`, `docker_check.sh`, `gpu_session.sh`, `bench_copy.cu` | local build and checks |
| `notes/optimizations.tex` / `.pdf` | notes on the optimizations, with measurements |

## Build and test

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j     # what the platform runs
g++ -O2 -std=c++17 -fopenmp -o solution_cpu main.cpp solve_cpu.cpp     # CPU check build
./run_tests.sh build/solution && ./run_tests.sh                         # 21-point matrix
python3 fuzz.py /tmp/fuzz                                               # 61 more points, all modes
```

The test scripts need Python 3 with `numpy` and `gmpy2`.

## Runtime settings

All optional; read once in `fherma_init`.

| Variable | Default | Meaning |
|---|---|---|
| `FHERMA_IN`, `FHERMA_OUT` | chosen at setup | `hmm`, `staged`, `register`, `mapped`, `stream` |
| `FHERMA_AUTOTUNE` | on | `0`: no timing at setup, use `hmm` where possible |
| `FHERMA_CHUNKS`, `FHERMA_OUT_CHUNKS`, `FHERMA_A/B/C_CHUNKS` | per mode | pipeline chunking |
| `FHERMA_TWIDDLES` | `auto` | `table`, `gen` (twiddles from small tables) |
| `FHERMA_THREADS`, `FHERMA_SPIN_MS` | min(16, cores/2), 20 | host copy threads; how long they spin after a call |
| `FHERMA_PROFILE` | off | per-phase GPU times and host timeline on stderr |
